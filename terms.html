1. 서비스 소개

오티티픽은 재밌게 본 작품과 보고 싶은 장르, 구독 중인 OTT를 바탕으로 볼 작품을 추천하고, 작품별 채팅방과 후기 기능을 제공하는 무료 서비스입니다. 현재 시범 운영 중이며, 기능은 예고 없이 바뀌거나 중단될 수 있습니다.

2. 작품 정보

작품 정보, 평점, 포스터는 TMDB에서, OTT 편성 정보는 JustWatch에서 제공받습니다. 실제 편성과 다를 수 있으니 시청 전 각 OTT에서 확인해 주세요. This product uses the TMDB API but is not endorsed or certified by TMDB.

3. 이용자의 게시물

  • 채팅과 후기는 다른 이용자에게 공개됩니다. 개인정보(연락처 등)는 올리지 마세요.
  • 스포일러는 '스포' 표시를 켜고 올려주세요.
  • 욕설·비방·혐오 표현, 광고·도배, 불법 정보는 금지됩니다.
  • 여러 이용자에게 신고된 게시물은 자동으로 숨겨지며, 운영자가 삭제할 수 있습니다. 반복해서 위반하면 이용이 제한될 수 있습니다.
  • 게시물의 권리와 책임은 작성한 이용자에게 있습니다.

4. 계정
