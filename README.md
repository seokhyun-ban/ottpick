# 오티티픽 (OTTPick)

재밌게 본 작품과 지금 보고 싶은 장르, 구독 중인 OTT를 고르면 지금 바로 볼 작품을 딱 3개 골라주는 추천 앱 프로토타입이에요.

- 작품·평점·포스터: [TMDB](https://www.themoviedb.org) API
- 한국 OTT 편성 정보: JustWatch (TMDB watch providers)
- TMDB API 키는 각 사용자 브라우저에만 저장돼요.

This product uses the TMDB API but is not endorsed or certified by TMDB.
